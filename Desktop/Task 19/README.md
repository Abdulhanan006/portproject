# Developer Portfolio Projects Showcase

A modern, fully responsive Developer Portfolio Projects Showcase built with a Node.js/Express backend and an HTML/CSS/Vanilla JS frontend.

## Features
- **Dynamic Projects Loading:** Projects are fetched via a REST API from a JSON database.
- **Category Filtering & Search:** Filter projects by tech stack (Web, Mobile, AI, Python) or search dynamically.
- **Lightbox Preview:** Click on any project image for a larger, detailed view.
- **Premium UI/UX:** Features glassmorphism, smooth animations, dark/light mode toggle, and fully responsive layout.
- **Real-world Actions:** Links to Live Demos and GitHub repositories.

## Structure
- `/backend`: Node.js, Express server, JSON database, API Routes.
- `/frontend`: HTML, CSS, JavaScript.

## How to Run Locally

### 1. Start the Backend Server
```bash
cd backend
npm install
node server.js
```
The backend API will run on `http://localhost:5000`.

### 2. Run the Frontend
Simply open `/frontend/index.html` in your web browser (or use an extension like Live Server in VS Code).
